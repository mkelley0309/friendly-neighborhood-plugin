An assignment carries *proportional* admin only — assignment, checklist, handoff, lessons. If one grows into multi-session work with real research or design, promote it to a **workstream** (`workstreams/`).

This index answers *what exists and is it done*. [`_log.md`](_log.md) is the **durable record** of everything completed — the assignment folder is deleted once its entry is written, so completed rows above link to the log rather than to a folder that no longer exists.
