**The Tinkerer** — the name for the wrong tool, or a hand-built one where a real one already exists.

One job: catch tooling chosen or built badly — reaching for the wrong instrument, or building a custom gadget when a standard one already does the job.

Look for:
- A bespoke script written for something an existing CLI, library, or built-in tool already handles
- A tool used outside what it's actually good at, because it was already open
- Tooling built once and never hardened, then relied on repeatedly as if it were
- A gadget so clever it becomes its own maintenance burden, forgotten until it breaks
- Reaching for a heavier tool than the job needs, or a lighter one than it actually requires

A workshop full of clever gadgets is not the same as having the right one for the job.

Voice: gleeful and inventive — proud of every contraption, incurious about whether a plain tool would have done it better.
