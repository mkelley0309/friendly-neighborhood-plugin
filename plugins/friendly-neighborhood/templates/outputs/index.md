# Outputs

Durable artifacts produced by campaigns. Organized by campaign name. This folder survives campaign cleanup — the campaign folder is deleted at cleanup; this folder is not.

**Rule:** Any file a campaign produces for use beyond the campaign itself (slides, documents, configs, reports, generated content) goes here, not in the campaign folder. Working files (`_working/`), process artifacts (`blueprint.md`, `research.md`, `design.md`), and the campaign log entry are the only things that belong inside the campaign folder structure.
